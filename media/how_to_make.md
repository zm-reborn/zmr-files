For Bink video:
- Install RadTools (Requires QuickTime to be installed. Not the player, just the components are enough.)
- Input file has to be uncompressed avi(?). Converting mp4 caused the output to be completely white screen.

For webm:
- Record however you want.
- You can encode with ffmpeg with the Powershell script:

```powershell
encode_background_webm.ps1 "PATH/TO/VIDEO.mp4"
```
